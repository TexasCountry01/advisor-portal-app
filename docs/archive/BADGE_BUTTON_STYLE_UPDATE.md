# Badge & Button Style Update

**Date:** February 16, 2026

## What Changed

We updated how **status labels** and **action buttons** look across the entire portal so users can immediately tell the difference between something that's just showing information and something they can click.

## The Rule

| Element | How It Looks | Example |
|---------|-------------|---------|
| **Status labels** (Submitted, Accepted, On Hold, etc.) | Outlined — white background with a colored border | <span style="border: 1.5px solid green; color: green; padding: 2px 8px; border-radius: 4px;">Completed</span> |
| **Action buttons** (Edit, Delete, Submit, etc.) | Solid — filled color background with white text | <span style="background: #0d6efd; color: white; padding: 2px 8px; border-radius: 4px;">Edit Case</span> |

**In short:** If it's just a label telling you the status, it has a colored border with no fill. If you can click it to do something, it's solid and filled in.

## Exceptions

- **Unread message counts** — Stay solid red so they stand out
- **Stat tiles** at the top of dashboards — Stay the same (gradient backgrounds)
- **View / Download / Delete icons** — Keep their existing subtle style

## Where It Applies

Every page in the portal — all dashboards (Member, Technician, Admin, Manager), case detail pages, audit logs, reports, user management, and review screens.

## Why

Users were confused because solid-colored status labels looked like clickable buttons. The outlined style makes it clear they're just labels, while the solid buttons clearly invite a click.
