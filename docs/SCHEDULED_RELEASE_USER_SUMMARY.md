# Update: Same-Day Scheduled Releases Now Work

**Date:** March 17, 2026  
**Status:** Ready for testing

---

## What Changed

You can now **schedule a case release for later the same day** — not just the next day or beyond.

---

## Before

- You could pick a date and time, but the system only saved the **date**
- The time you selected was ignored
- Same-day scheduling didn't work — cases wouldn't release until the next morning

## Now

- The system saves both the **date and time** you select
- Schedule a release for 3:00 PM today, and it releases at 3:00 PM
- Dashboards and case detail pages now show the **scheduled time** alongside the date

---

## What You'll See

- **Case detail page:** "This case will be released on: March 17, 2026 at 3:00 PM"
- **Dashboard release column:** Shows date + time (e.g., "03/17/26 3:00 PM")
- **Reschedule modal:** Shows current release date + time

---

## How to Use

1. Complete a case as usual
2. Choose "Schedule for later"
3. Pick a **date** and **time** (in CST)
4. The case will release and the member will be notified at that exact time

Everything else works the same — immediate release, reschedule, and release-now buttons are all unchanged.
