# Panic Button / Urgent Contact - Options

## The Problem

When an advisor has an emergency, they need a fast way to reach the benefits team through the portal. Without this, they'll default to emailing the old email inbox directly.

Currently, the portal's chat feature only works on existing cases. There's no way to send an urgent message or ask a general question without having a case open.

---

## Option 1: Add an "Urgent" Flag to Case Chat

When sending a message on an existing case, the advisor gets a checkbox to mark it as **URGENT**. Urgent messages show up with a red flag on the technician's dashboard and trigger an immediate email alert.

**Pros:**
- Simple addition to an existing feature
- Keeps communication tied to the relevant case

**Cons:**
- Only works if the advisor already has a case open
- Doesn't cover general questions unrelated to a case

---

## Option 2: Standalone "Contact Benefits Team" Form

A new "Contact Us" button in the navigation bar, available on every page. Opens a form with a subject line, message, and a priority selector (Normal or Urgent). Messages go into a queue visible to staff on their dashboard.

**Pros:**
- Works even without a case open
- Covers both urgent issues and general questions in one feature
- Always accessible from any page

**Cons:**
- New feature to build and maintain
- Staff need a new inbox/queue to monitor

---

## Option 3: Both — Urgent Chat on Cases + General Contact Form

- **On existing cases:** Add an "Urgent" flag option to chat messages
- **For general questions (no case):** Add a standalone contact form with an urgent option
- Both types of messages appear in a single staff inbox

**Pros:**
- Covers every scenario — case-specific emergencies and general questions
- Most complete solution

**Cons:**
- Largest effort to build
- Two paths to manage

---

## Option 4: Dedicated "Panic Button" on the Dashboard

A prominent red button always visible on the advisor's dashboard. One click opens a simple form — just a message box. Everything sent through it is automatically flagged as URGENT. It can optionally be linked to a specific case or sent as a standalone message.

**Pros:**
- Fastest path for emergencies — designed for speed
- Highly visible, hard to miss
- Clear purpose — advisors know exactly what it's for

**Cons:**
- Could be overused if not clearly labeled for true emergencies
- Doesn't address general (non-urgent) questions

---

## Option 5: Replace "Beta Feedback" with "Need Help?"

The "Beta Feedback" button in the navigation bar will eventually be removed. Replace it with a "Need Help?" or "Contact Us" button that opens a form with a priority selector (Normal or Urgent).

**Pros:**
- Reuses an existing spot in the navigation — no added clutter
- Covers both urgent and general questions
- Clean transition as beta period ends

**Cons:**
- Less prominent than a dedicated panic button
- Advisors may not immediately notice the change

---

## Summary

| Option | Covers Emergencies | Covers General Questions | Needs a Case |
|--------|-------------------|------------------------|--------------|
| **1 - Urgent Flag on Chat** | Yes | No | Yes |
| **2 - Contact Form** | Yes | Yes | No |
| **3 - Both** | Yes | Yes | Either |
| **4 - Panic Button** | Yes | No | Optional |
| **5 - Replace Beta Feedback** | Yes | Yes | No |
