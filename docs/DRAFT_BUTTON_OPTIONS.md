# Draft Case Buttons - Simplification Options

## Current State

When viewing a Draft case, the top of the page shows **5 items** in a row:

**Draft** | **← Back to Dashboard** | **✓ Submit Case** | **✎ Edit Draft** | **🗑 Delete Draft**

This feels crowded. Below are options to reduce it.

---

## Option A: Combine Edit and Delete into One Button

Edit Draft becomes the main button with a small dropdown arrow. Clicking the arrow reveals "Delete Draft" as a menu option underneath.

**What you'd see:**

**Draft** | **← Back to Dashboard** | **✓ Submit Case** | **✎ Edit Draft ▼**

*(4 items — down from 5)*

---

## Option B: Move Delete Off the Button Bar

Remove "Delete Draft" from the top bar. Place it as a small link at the bottom of the case page or inside the Edit Draft screen. Deleting a draft is a rare action and doesn't need to be front and center.

**What you'd see:**

**Draft** | **← Back to Dashboard** | **✓ Submit Case** | **✎ Edit Draft**

*(4 items — down from 5)*

---

## Option C: Remove "Back to Dashboard"

The Dashboard link already exists in the top navigation menu, and the browser back button also works. Removing it saves space without losing access.

**What you'd see:**

**Draft** | **✓ Submit Case** | **✎ Edit Draft** | **🗑 Delete Draft**

*(4 items — down from 5)*

---

## Option D: Remove Both "Back to Dashboard" and "Delete Draft"

Combines Options B and C. Keeps only the two primary actions. Delete moves to the bottom of the page or inside the Edit screen.

**What you'd see:**

**Draft** | **✓ Submit Case** | **✎ Edit Draft**

*(3 items — down from 5)*

---

## Option E: Group Secondary Actions into a Dropdown

Keep "Submit Case" as the main button. Put "Edit Draft", "Delete Draft", and "Back to Dashboard" inside a single "More Actions" dropdown menu.

**What you'd see:**

**Draft** | **✓ Submit Case** | **More Actions ▼**

*(3 items — down from 5)*

---

## Summary

| Option | Items Shown | What Changes |
|--------|-------------|--------------|
| **Current** | 5 | Nothing |
| **A** | 4 | Edit + Delete become one split button |
| **B** | 4 | Delete moves to bottom of page |
| **C** | 4 | Back to Dashboard removed (still in nav menu) |
| **D** | 3 | Both Dashboard and Delete removed from bar |
| **E** | 3 | Secondary actions grouped into one dropdown |
