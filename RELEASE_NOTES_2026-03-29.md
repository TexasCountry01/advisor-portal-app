# What's New — March 29, 2026

## Portal Updates

- **ProFeds Brand Colors** — The entire portal now uses official ProFeds brand colors (Blue, Gold, Red, Dark Blue, Purple, Dark Gray) consistently across all pages, badges, buttons, and email notifications
- **Broadcast Messaging** — Admins, managers, and level-3 technicians can send broadcast messages to all active members and delegates with email notifications
- **Delegate Alert Preferences** — Each delegate now has separate toggles for Email alerts and Portal Notification alerts, individually configurable
- **Ask a Question Email Toggle** — Members can choose whether to also send an email to the benefits team when submitting a question through the messaging portal
- **Need Help? Button** — New help button on the member dashboard with an explanatory guide
- **Staff Notifications Tab** — Technicians, admins, and managers now have a Notifications tab in the navbar for case chat messages and member change requests
- **Sticky Case Detail Header** — The case header stays visible when scrolling through long case details
- **Additional Report Uploads** — Technicians can upload additional reports beyond the originally requested count
- **Delete Documents** — Added a delete button to the Additional Documents section on cases
- **Report Titles** — Report titles now display the employee name and member (account holder) name
- **Delete Draft from Edit Page** — The Delete Case button has been moved to the edit page (draft/submitted cases only)
- **Draft Banner Improvements** — Draft banner is now collapsible with a caret, titled "You Have Case(s) in Draft Mode"
- **Case Detail Layout** — Status badge moved under employee name; Edit Draft and Submit Case buttons shown for draft cases
- **Cancellation Notifications** — Technicians receive a staff notification when a member cancels a case
- **Unified Status Badge Colors** — Consistent badge colors across all dashboard views
- **Bolder Buttons** — Button text and borders are now heavier for better visibility
- **Portal Feedback** — "Beta Feedback" renamed to "Portal Feedback"
- **Delegate Management Fix** — Fixed delegate access for admin and manager roles
- **Document Delete Audit Trail** — Deleting a document now correctly records in the audit log
- **Message Reply Email** — Updated reply notification email content and formatting
