Case Release Scheduling
When OFF, all completed cases are released to the member immediately.
Technicians can override this when completing each case. All times are in CST.
Runs daily via cron job. When OFF, delayed cases must be released manually.
Server is UTC. 12:00 UTC = 6:00 AM CST.
How It Works:
  1. Technician completes a case and chooses release timing (immediate, delay, or specific date)
  2. If delayed, the case is marked "completed" but stays hidden from the member
  3. The daily cron job releases cases whose scheduled date has arrived and sends the completion email
