Available Credit Values
Technicians can assign these credit values to cases based on complexity.
Default: 0.5 (partial report), 1.0 (single report), 1.5-3.0 (multiple scenarios)
Credit Assignment Examples:
  • Single report: 1.0 credit
  • 2 scenarios: 1.5 credits (1.0 base + 0.5)
  • 3 scenarios: 2.0 credits (1.0 base + 0.5 + 0.5)
  • 4+ scenarios: 2.5-3.0 credits

Technical Notes Template

This template is auto-populated into the "Notes to the ProFeds Member" field when a technician accepts a case. Technicians can also insert it manually via the Insert Template button in the notes editor.

Template Tips:
  • Use <h3><u>HEADER</u></h3> for section headers (underlined)
  • Use <a href="..." target="_blank">CLICK HERE</a> for links
  • Use <p>&nbsp;</p> for empty placeholder sections
  • Changes take effect immediately for new case acceptances and template insertions
Portal Feedback Email Notifications

Configure email addresses to receive notifications when a member submits portal feedback. Use the toggle to enable or disable notifications for each email individually.

Note: Feedback notification emails are sent independently of the master email toggle. They will be sent as long as the individual toggle is enabled and an email address is provided.
