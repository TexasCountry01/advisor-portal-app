Metric Definitions
Reports Generated — Cases released (status = completed) within the date window.
Submitted for Review — Review submission events (one case can generate multiple).
On-Time Delivery % — date_completed ≤ date_due ÷ completed cases with a due date.
ProFeds Errors — Member-flagged error modification cases, by when the mod was submitted.
Avg Production Cycle Time — Avg days from member submission to tech release.
Avg Readiness Window — Avg days finished ahead of due date. Positive = early.
Report Accuracy — Completed cases with no PF error flag ÷ all completed cases.
Initial Submissions — All non-draft cases submitted by advisors in the window (by date_submitted).
L1/L2 Review Accuracy — % of L1/L2 review outcomes where the case was approved first-pass (no revisions or corrections needed).
Level 1/2 Accuracy Rate — Cases returned to the tech by L3 with revisions requested.
Corrected by L3 — L3 found an issue and corrected it directly without returning the case to the tech.
