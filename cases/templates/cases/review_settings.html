How Review Settings Work
  • Toggle ON: When the technician marks a case at that tier as completed, it automatically goes to Pending Review instead of Completed.
  • Toggle OFF: The case goes directly to Completed and can be released to the member immediately.
  • Default behavior: Tier 1 requires review (ON), Tier 2 and Tier 3 do not (OFF). These defaults apply when no explicit setting exists for a technician.
  • Ad-hoc reviews: Any technician can still request an ad-hoc review from the case detail page, regardless of these settings.
